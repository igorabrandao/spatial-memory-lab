# Contributing Guidelines

## Philosophy

This project is an experimental learning system.

Contributions should:
- prioritize clarity over complexity
- be modular
- be explainable

## Workflow

1. Create a branch
2. Implement small, testable changes
3. Ensure visual/debug output
4. Open a PR

## Code Style

- snake_case for functions
- PascalCase for classes

## Rules

- No large auto-generated code
- No magic solutions without explanation
